### 3.3 关键设计决策

#### 3.3.1 事件队列化 — 避免 Windows Hook 超时

Windows 的 `SetWindowsHookEx` 有严格超时（约 100ms），Hook 回调阻塞会导致事件被静默丢弃，尤其是双击事件（必须快速连续到达）。

**解决方案**：pynput 回调仅做 `queue.put()`，所有重型操作（JSON 序列化、窗口检测、日志写入）都在独立 Worker 线程完成。

```python
# Hook 回调 — 极轻量，仅入队
def _hook_on_click(self, x, y, button, pressed) -> bool:
    self._q.put(("click", int(x), int(y), self._btn(button), pressed, time.monotonic()))
    return True

# Worker 线程 — 所有重型处理在此
def _worker_loop(self) -> None:
    while self._running:
        item = self._q.get(timeout=0.5)
        if item is None: break
        tag, *args = item
        if tag == "click": self._proc_click(*args)
        # ...
```

#### 3.3.2 截图异步写入 — 不阻塞采集循环

JPEG 替换 PNG：文件大小缩小约 4 倍，写入耗时降低约 3 倍。使用 daemon 线程异步写入磁盘，采集主循环不等待 I/O 完成。

```python
threading.Thread(
    target=lambda: cv2.imwrite(_path, _bgr, [cv2.IMWRITE_JPEG_QUALITY, 90]),
    daemon=True,
).start()
```

#### 3.3.3 目标窗口过滤 — 剔除无关事件

选择目标进程后，通过**窗口矩形 + PID 双重过滤**，自动剔除：
- 任务栏点击
- 录屏工具自身的操作
- 其他窗口的干扰事件

窗口矩形缓存 200ms，避免高频鼠标移动时的重复 ctypes 调用。

#### 3.3.4 HiDPI 适配

物理分辨率自动降采样到逻辑分辨率，确保帧中像素坐标与 pynput 报告的屏幕坐标 1:1 对应：

```python
if bgr.shape[1] != logical_w or bgr.shape[0] != logical_h:
    bgr = cv2.resize(bgr, (logical_w, logical_h), interpolation=cv2.INTER_AREA)
```

### 5.2 服务启动机制

`UIRecorderCoreServer` 在后台 daemon 线程中启动 Flask 服务：

1. 检测是否已有外部实例运行（健康检查 `/api/v1/health`）
2. 将 `urecorder/` 加入 `sys.path`
3. 通过 `sys.modules` 别名映射解决 `view` → `urecorder.view` 的导入路径问题
4. 注册所有蓝图后启动 Flask（`debug=False, use_reloader=False`）
5. 轮询等待服务就绪（最长 15 秒）

```
单目录 exe（recorder/ + urecorder/ + 依赖）
    ↓  Inno Setup / zip
安装包 (AgentRunnerRecorder-Setup.exe / .zip)
```

### 8.2 CI/CD

GitHub Actions 自动构建（`.github/workflows/build.yml`），推送 tag 触发：

```bash
git tag v1.0.0
git push origin v1.0.0
```

产物自动上传到 Releases（Draft 状态，手动审核后发布），支持 Windows (exe) 和 macOS (zip)。

## 九、项目亮点

1. **双层架构协同**：桌面录屏 (`recorder`) + Web 服务 (`urecorder`) 通过桥接层无缝协同，既能独立运行也能联动工作
2. **性能优化到位**：Hook 队列化、截图异步写入、窗口矩形缓存（200ms TTL）、JPEG 替代 PNG（4x 文件缩小）
3. **跨平台 UI Automation**：统一抽象 Windows (uiautomation) / Linux (AT-SPI) / macOS (AX API) 三平台控件采集
4. **完整测试工作流**：录制 → 报告 → AI 测试用例 → GuiRunner 自动化执行 → YOLO 数据集
5. **Cython + PyInstaller**：源码编译为原生 .pyd，保护知识产权并提升启动速度
6. **目标窗口智能过滤**：矩形 + PID 双重检测，自动剔除任务栏/工具栏等无关事件
7. **多格式报告导出**：Markdown/HTML/Word/JSON/ZIP 5 种格式 + HAR 推送到 GuiRunner
