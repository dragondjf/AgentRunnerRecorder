# UIRecorder 系统需求文档

## 1. 项目概述

UIRecorder 是基于智能体驱动的测试平台，实现UI操作录制、AI智能分析和测试用例自动生成。

### 核心目标
- 自动化录制UI操作（鼠标、键盘）
- 智能捕获操作截图
- AI视觉模型分析界面功能
- 生成结构化测试文档
- 多格式导出（Word/PDF/Markdown）
- 专业图片标注编辑

### 目标用户
测试工程师、产品经理、UI设计师、开发人员

## 2. 功能需求

### 2.1 系统监控
- **鼠标监控**：捕获点击位置、按钮类型、自动截图、时间戳
- **键盘监控**：记录输入文本、首末字符截图、超时保存（3秒）
- **截图管理**：自动命名、分类存储、预览、批量导出

### 2.2 事件录制
- **操作记录**：唯一ID、操作类型、中文步骤标题、Markdown格式、SVG缩略图
- **数据存储**：JSON格式、records.json管理、自动保存
- **项目管理**：独立目录、数据隔离、项目切换

### 2.3 AI分析
- **图像分析**：集成Qwen-VL模型、生成标题描述、批量分析、流式输出
- **上下文理解**：自定义上下文、需求说明、智能分析
- **结果存储**：保存AI结果、更新标题描述、编辑优化

### 2.4 图片编辑
- **基础功能**：文字标注、画笔绘制、箭头、椭圆矩形、高亮、序号（1-10）、马赛克
- **高级功能**：图片裁剪、撤销重做、元素选择、属性面板、拖拽上传
- **文件操作**：上传下载、JSON导入导出、批量导出、截图删除

### 2.5 数据导出
- **导出格式**：Word、PDF、Markdown、HTML、ZIP、测试文档、帮助文档
- **导出内容**：操作步骤、截图、AI结果、自定义模板

### 2.6 API接口
- **核心API**：数据读写、配置管理、监控控制、项目管理、状态查询
- **AI服务API**：单图分析、批量分析、流式输出
- **导出API**：格式列表、文件导出

### 2.7 Web界面
- **主控制台**：项目管理、监控状态、操作列表、AI结果、Markdown渲染
- **图片编辑器**：专业工具栏、画布、选项面板、属性面板

## 3. 非功能需求

- AI分析<5秒
- 导出<10秒

### 可靠性
- 系统稳定性>99%
- 数据丢失率<0.1%
- 截图成功率>95%

### 易用性
- 界面直观
- 操作反馈及时
- 使用帮助
- 快捷键支持

### 安全性
- 数据本地存储
- 数据加密
- 访问控制
- 安全日志

## 4. 系统架构

### 后端
- Flask API服务器（52000端口）
- 静态文件服务器（52001端口）
- AI服务（52002端口）
- 核心监控模块（core/）
- 数据管理模块（utils/）

### 前端
- 主界面（index.html）
- 图片编辑器（editor.html）
- 原生JavaScript实现
- 响应式设计
